## Phase 1: MVP (예상 3~4주, 바이브코딩 기준 가변) — **Claude Code 전용**

### 목표
초보자가 한 번 설치하면, AI가 **쉬운 한국어로 말하고**, **위험 작업을 자동으로 막아 주고(+백업·되돌리기)**, **막히면 자가진단으로 다음 행동을 안내**받는다. 그리고 **SoDamHarness 자신이 안전**하다.

> 만들기 직전 구체 초안·명세: **[06_CORE_DRAFTS.md](./06_CORE_DRAFTS.md)** (AGENTS.md 본문·guard.mjs 동작·backup/undo·commands, 손시뮬 H1~H7 닫음).

### 기능
- [ ] 안전 가드레일 — 삭제·덮어쓰기·배포·외부전송을 **PreToolUse hook으로 확인/차단 + 자동 백업 + 되돌리기**
- [ ] 초보자 말투·페르소나 — **Skill로 전달**(`skills/beginner-tone`, Claude Code 자동 로드). 같은 내용 AGENTS.md는 Codex 공용으로 별도. 쉬운 한국어·기술용어 최소화
- [ ] 원클릭 설치·자가진단 — 설치 + 상태 확인 + 문제 해결 안내(commands)

### 데이터
- 설정 프로필 / 안전 규칙 / 백업 기록 / 진단 기록 (전부 로컬 `홈폴더/.sodamharness/`, **토큰 저장 금지**)

### 인증
- **없음** (로컬 플러그인)

### "진짜 제품" 체크리스트
- [ ] 실제 hooks가 동작 — 위험 명령이 **실제로 실행 전에 막힘**(말로만 X)
- [ ] 실제 백업 파일이 생기고 **되돌리기로 복구됨**(목업 X)
- [ ] **Windows·Mac 둘 다** 설치·차단·백업 동작
- [ ] 다른 사람 컴퓨터에 **마켓플레이스에서 설치**해 처음부터 끝까지 됨
- [ ] **SoDamHarness 자신이 토큰·비밀에 접근 안 함**이 코드로 확인됨(01_PRD §8)
- [ ] **왕초보 README + 가이드 작성**(사전준비~다운로드~빠른시작~사용~되돌리기~문제해결~제거, 01_PRD §10 기준) — **구현 완료의 일부**
- [ ] 초보자 1~3명이 **문서만 보고** 설치→첫 작업→되돌리기까지 도달(문서 수용 기준, §10.4)

### Phase 1 시작 프롬프트 (복사해서 바로 사용)

- 초보자 말투·페르소나 (Skill로 전달: skills/beginner-tone, 쉬운 한국어)

- 먼저 계획을 보여주고, 위험 변경은 확인받고 진행

## Phase 2: 확장 (예상 2~3주)

### 전제 조건
- Phase 1이 Windows·Mac 양쪽에서 안정적으로 동작·검증됨

### 목표
AI가 한 일을 초보자가 쉽게 보고 되돌릴 수 있게 하고, AI가 "다 됐어요" 전에 스스로 점검하며, **같은 하네스를 Codex에서도** 쓰게 한다.

### 기능
- [ ] 활동 기록(쉬운 관측) — "AI가 방금 뭘 했는지" 쉬운 타임라인 + 그 작업 되돌리기
- [ ] 자가검증 루프 — 종료 전 실제 동작 점검 + **증거 보고**(실행 로그/체크리스트)
- [ ] Codex 지원 — **말투·지침은 `AGENTS.md` 그대로 재사용**, 안전은 Codex 방식으로 매핑:
  - `~/.codex/config.toml`의 **`approval_policy`**(untrusted/on-request 등) + **`sandbox_mode`**(read-only/workspace-write)로 보수적 기본값 설정
  - (Claude의 hook `deny` ↔ Codex의 승인정책+샌드박스 = 같은 목표, 다른 장치)

### 추가 데이터
- 활동 기록 / 자가검증 기록 엔티티 추가
- 설정 프로필 `target_tool`에 `codex` 추가

### ⚠️ Codex 주의 (모순 해소됨)
말투·지침은 `AGENTS.md` 공용 표준이라 **거의 그대로** 통한다(확인됨). 단, **안전 차단 장치는 다르다** — Claude는 hooks, Codex는 `config.toml` 승인정책+샌드박스. "양쪽 100% 동일 hook"은 약속하지 말고, **"같은 안전 결과를 각 도구 방식으로"** 로 범위를 명확히.

### 통합 테스트
- Phase 1 기능(차단·백업·되돌리기·말투)이 여전히 정상 동작하는지 확인

## Phase 3: 고도화 (예상 3~4주)

### 전제 조건
- Phase 1 + 2가 안정적으로 운영 중

### 목표
초보자에게 **맞춤 설정**을 추천하고, **정식 공개**해 누구나 쓰게 한다.

### 기능
- [ ] 맞춤 마법사 — 질문에 답하면 **안전 강도·자율성 등급 자동 추천**

### 주의사항
- 공개 전 **이름 충돌 확인**(npm/GitHub/마켓) — 01_PRD §7

- hooks 보안 재검토(3~6개월)
- **sunsetting 도구(Vibe Kanban·Omnara 등) 의존·차용 금지**(유지보수 중단 안내 있음)
