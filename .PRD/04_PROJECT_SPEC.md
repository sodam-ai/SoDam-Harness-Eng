## 기술 스택

| 영역 | 선택 | 이유 |
|------|------|------|
| 제품 형태 | **Claude Code 네이티브 플러그인** (마켓플레이스 배포) | 공식 구조라 호환·배포 쉬움. GitHub repo = 마켓플레이스 |
| 말투·지침 | **Skill**(`skills/beginner-tone`) + **선택적 `AGENTS.md`** | ⚠️플러그인 동봉 AGENTS.md/CLAUDE.md는 **자동 로드 안 됨**(확인됨) → 말투는 **Skill로 전달**. AGENTS.md는 Codex·Cursor·Gemini 공용 표준으로 별도 활용 |
| 안전 차단(가드레일) | **Node.js 훅 (.mjs)** + PreToolUse | `deny`로 AI가 못 뚫는 결정적 차단. **Windows·Mac 안 깨짐**(`os.homedir()`,`windowsHide:true`) |
| 안전 차단(Codex, P2) | **`config.toml`** `approval_policy` + `sandbox_mode` | Codex는 hook이 아닌 **승인정책+샌드박스 2중 모델**(확인됨). 같은 목표, 다른 장치 |
| 설정·백업 저장 | **로컬 파일** `홈폴더/.sodamharness/` | 서버·DB 없음. **토큰·비밀 저장 금지**(§보안) |
| 배포 | **GitHub 마켓플레이스 repo** | 클릭 설치, 자동 업데이트. 공식/검증 경로만 |
| 인증 | **없음** | 로컬 플러그인 (인터뷰 확정) |
| 라이선스 | **Apache-2.0** | 상업 사용 허용·보증 없음. 차용 코드는 NOTICE 표기 |

> ⚠️ **.bat / PowerShell 훅 금지.** 한글(CP949)·줄바꿈(CRLF) 깨짐을 피하려면 훅은 반드시 **Node.js(.mjs)**.

## 프로젝트 구조 (Claude Code 플러그인 표준)

```
sodamharness/
├── .claude-plugin/
│   └── plugin.json          # 플러그인 정보(이름·버전·설명·라이선스)
├── skills/
│   ├── beginner-tone/       # ★ 초보자 말투·지침 (플러그인은 Skill로 전달 — 자동 로드됨)
│   └── self-check/          # (Phase 2) 자가검증 루프
├── commands/
│   ├── install.md           # 설치
│   ├── status.md            # 상태 확인(자가진단)
│   ├── fix.md               # 문제 해결 안내
│   └── undo.md              # 되돌리기(백업에서 복구)
├── hooks/
│   ├── hooks.json           # ★ 어떤 훅을 언제 돌릴지(PreToolUse 등) — hooks/ 안에 위치
│   ├── guard.mjs            # 위험 작업 차단/확인 (Node.js)
│   └── backup.mjs           # 자동 백업
├── AGENTS.md                # (선택) Codex·타도구용 공용 지침 — 플러그인 자동 로드 아님
├── .gitignore               # .sodamharness/·로컬 설정·비밀값 Git 추적 제외
├── package-lock.json        # 의존성 버전 고정(공급망 방어)
├── README.md                # 왕초보 안내
├── LICENSE                  # Apache-2.0
└── NOTICE                   # 참고/차용한 외부 코드 고지
```

> 마켓플레이스 배포 시 repo에 `.claude-plugin/marketplace.json` 추가.
> (Phase 2) Codex용은 같은 `AGENTS.md` 재사용 + `config.toml` 보수 기본값 템플릿 제공.

## 절대 하지 마 (DO NOT)

> AI에게 코드를 시킬 때 반드시 함께 공유.

**안전 동작**
- [ ] 위험 차단을 **"말로만" 처리하지 마** — 반드시 PreToolUse hook `deny`/`ask`로 실제 막아라
- [ ] **백업 없이** 삭제·덮어쓰기를 실행하지 마
- [ ] 목업/하드코딩으로 "차단됨·백업됨"이라고 **거짓 보고하지 마**(실제 파일로 증명)

**제품 자신의 보안 (1순위 — 어기면 제품 존재 이유 붕괴)**
- [ ] **토큰·비밀번호·인증파일(`auth.json` 등)에 접근/저장하지 마** (근처도 가지 마)
- [ ] **외부 코드/스크립트를 자동으로 내려받아 실행하지 마**
- [ ] **데이터·로그를 외부로 전송하지 마**(서버 없음 원칙)
- [ ] **유지보수 중단(sunsetting) 도구(Vibe Kanban·Omnara 등)에 의존·차용하지 마**
- [ ] 검사한 **명령/경로를 직접 실행하거나 `eval` 하지 마**(검사는 데이터로만)
- [ ] 경로에 **`..`·작업폴더 밖 절대경로·심볼릭 링크**가 있으면 거부(경로 조작 방지)

**기술/호환**
- [ ] 훅을 **.bat / cmd / PowerShell / bash로 작성하지 마** — Node.js(.mjs)만
- [ ] 경로를 **하드코딩하지 마**(`C:\Users\...`, `$HOME` 직접) — `os.homedir()` 사용
- [ ] 사용자의 **기존 설정·다른 플러그인·기존 파일을 임의로 덮어쓰지 마**
- [ ] AGPL 등 **양립 불가 라이선스 코드를 차용하지 마**(MIT/BSD/Apache만)
- [ ] 타사 **상표·로고·브랜드명**(Claude·Codex·Anthropic·OpenAI 등)을 **공식 제휴·보증처럼 쓰지 마**(명목적 표시만)
- [ ] 샘플·데모·스크린샷·테스트 파일에 **개인정보·타인 저작물·비공개 정보**를 넣지 마
- [ ] "100% 사고 방지"·"법적으로 100% 안전"이라고 **과장하지 마**(참고용·사용자 책임·법률 자문 아님 고지)

## 보안 수용 기준 (OWASP ASVS · Secure by Design — 상세 01_PRD §8)

> 보안은 **핵심 요구사항**. 아래는 구현·검수 시 "통과/실패"를 가르는 구체 기준이다.

- [ ] **비밀정보(Must)**: 코드·로그·문서·Git에서 token/secret/auth/key 접근 **0건**. `~/.codex/auth.json`·`~/.claude` 자격증명 **미접근**.
- [ ] **공급망(Must)**: 의존성 최소 + `lockfile` 고정. 외부 코드 자동 다운로드/실행 **0건**. 설치·업데이트는 공식 경로만.
- [ ] **입력 검증(Must)**: AI의 명령·경로를 신뢰하지 않음. `../`·시스템 경로·체인 기호(`;` `&&` `|`) 탐지·차단. `eval`/직접 실행 **0건**.
- [ ] **접근 통제(Must)**: 위험 3등급(치명=`deny`/주의=`ask`+백업/안전). 권한 상승 **0건**.
- [ ] **로컬 저장(Should)**: `~/.sodamharness/`는 **본인 권한만**, 비밀값 저장 **0건**, `.gitignore` 제외.
- [ ] **보안 설정(Should)**: 디버그 off, 민감정보 로그·에러 노출 **0건**, 개발/배포 분리.
- [ ] **정직성(Must)**: "100% 보장" 문구 **0건**(참고용·사용자 책임 고지).
- **N/A(현 구조)**: 로그인·세션/JWT·CORS/쿠키/보안헤더·SQLi·XSS·파일업로드 — 서버·웹·DB·업로드가 없어 해당 없음. (P2에서 SQLite→파라미터 바인딩, HTML 표시→이스케이프 적용)
