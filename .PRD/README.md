## 핵심 결정 한눈에 (v2)

- **대상**: 개발·AI·IT 모두 처음인 완전 초보자(10대 포함) + 본인(공유용).
- **형태**: 마켓플레이스 플러그인(클릭 설치). **대상**: Claude Code 먼저 → Codex(P2).
- **MVP**: 안전 가드레일(**차단·확인·백업·되돌리기**) + 초보자 말투(**AGENTS.md**) + 원클릭 설치·자가진단. **Claude Code 전용.**
- **차별화(실명 비교)**: Hookify·CodeGuard·Codacy + 설치형 하네스(wshobson/agents·claude-code-harness·ai-engineering-harness·OpenHarness)는 **전부 개발자·영어**. → 우리 해자 = **완전 초보자 + 한국어 + 자기 사고 방지 + 한 묶음 + AGENTS.md 다도구 + 제품 자신이 가장 안전.**
- **형제 프로젝트 경계**: 서브에이전트 "팀 설치"는 AgentRoster 영역 → SoDamHarness는 안전·말투·설치만(범위 충돌 방지).
- **기술**: 네이티브 플러그인 + **Node.js(.mjs) 훅**(.bat/PS 금지로 한글·줄바꿈 문제 회피). 말투=AGENTS.md.
- **로그인**: 없음(로컬·서버 없음).
- **사용자 문서**: 왕초보 README·가이드(사전준비~다운로드~빠른시작~사용~되돌리기~문제해결~제거)는 **구현 완료의 일부**(§10). Troubleshooting·예상 실패까지 미리 문서화.
- **라이선스/상업적 사용**: **Apache-2.0**(작업 기준 — 최종 확정은 결정 필요) → 수정·복제·포크·재배포·판매·서비스·교육·**고객사 납품 가능**(NOTICE·고지 보존). 단 **AI 모델 약관·API 요금·외부 서비스 약관**은 사용자 별도 확인. **법률 자문 아님.** 상세 §9.

## ⚠️ 꼭 기억할 위험 (v2)

1. **제품 자신의 보안이 1순위.** 비공식 AI 도구가 실제로 토큰을 훔친 사고(2.9만 다운로드) 발생 → SoDamHarness는 **토큰·비밀 접근 0, 외부 코드 자동실행 0, 외부 전송 0.** **§8은 OWASP ASVS·Secure by Design 기준 정식 요구사항(MoSCoW·수용 기준 포함)으로 작성됨.** (01_PRD §8, 04_PROJECT_SPEC 보안 수용 기준)
2. **안전 차단은 hooks `deny`로** — "말로만 막혀요" 금지.
3. **훅은 Node.js로만** — .bat/PowerShell 한글·줄바꿈 재발 방지.
4. **Codex는 안전 장치가 다름** — 말투는 AGENTS.md 공용, 안전은 `config.toml` 승인정책+샌드박스로 매핑(P2).
5. **스코프 방어** — 서브에이전트·MCP·원격제어·풀 관측은 범위 밖(초보자에게 과함, "쉬움" 목적과 충돌).
6. **"100% 사고 방지" 과장 금지** — 참고용·사용자 책임 고지.
