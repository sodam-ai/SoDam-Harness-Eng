## 0. 한 줄로 기억할 것

> **"똑똑하지만 위험할 수도 있는 AI 코딩 도구에, 초보자가 단추 한 번으로 채우는 안전벨트(하네스). 그리고 그 안전벨트 자체가 가장 믿을 수 있어야 한다."**
> 넓은 하네스 엔지니어링(지침·스킬·서브에이전트·hooks·MCP·관측·원격제어)은 **참고 지도**로만 쓰고, SoDamHarness는 그중 **초보자에게 꼭 필요한 안전 슬라이스**만 단단하게 만든다.

## 1. 제품 개요

### 한 줄 요약
개발도 AI도 처음인 사람이, Claude Code(이어서 Codex)에 **안전 가드레일 + 쉬운 말투 + 원클릭 설치**를 한 번에 깔 수 있게 해 주는, **스스로도 가장 안전한** 마켓플레이스 플러그인.

### 해결하는 문제
- AI 코딩 도구는 강력하지만, 잘못 쓰면 **파일 삭제·설정 덮어쓰기·잘못된 배포** 사고가 난다. 초보자는 이걸 **되돌리지 못한다.**
- 사고를 막는 "하네스"는 규칙 파일·hooks·설정을 손으로 만들어야 해서 **비개발자 진입 장벽이 너무 높다.**
- AI는 기본적으로 **개발자 말투**라 초보자가 이해하기 어렵다.
- **(추가 발견·확인됨)** "안전"을 표방하는 비공식 도구가 오히려 **계정 토큰을 훔친 실제 사고**가 있었다(§8). 초보자는 안전/악성을 구분 못 한다 → **믿을 수 있는 안전 하네스**가 시장 빈자리다.

### 핵심 가치 (차별점)
1. **완전 초보자 우선** — 개발·AI·IT 기기 처음(10대 포함)이 기준. "붙여넣기"조차 못 한다고 가정.
2. **"사고 방지"가 헤드라인** — 경쟁 제품은 "코드 취약점 점검"이 중심. 우리는 **"초보자가 되돌릴 수 없는 자기 사고를 막는 것"**(자동 차단·확인·백업·**되돌리기**)이 1순위.
3. **제품 자신이 가장 안전** — 토큰·비밀에 접근 안 하고, 외부 코드 자동 실행 안 하고, 누구나 들여다볼 수 있게 투명(§8). 위험한 비공식 도구는 **경고**해 준다.
4. **한 묶음(번들) + 한국어 기본** — 가드레일·말투·설치를 따로 고르지 않고 하나로, 전부 쉬운 한국어.
5. **여러 도구로 확장 쉬움** — 같은 말투·지침을 Claude Code는 **Skill**로, Codex·Cursor·Gemini는 **`AGENTS.md`**(공용 표준)로 전달 → 한 벌의 내용으로 여러 도구 커버(§3). *(플러그인 동봉 AGENTS.md는 Claude Code가 자동 로드하지 않음 — 확인됨)*

## 2. 사용자

### 주요 사용자
- **누구**: 개발·AI를 한 번도 안 해 본 사람. 비개발자 바이브코더, 일반인, 10대 학생, 메신저·컴퓨터·전자기기에도 익숙하지 않은 사람.
- **상황**: AI에게 자연어로 "이거 만들어 줘"라고 시키고 싶은데, **사고가 날까 봐 무섭고** 설정을 모를 때.
- **목표**: 복잡한 설정 없이 **안전하게** AI 코딩 도구를 쓰기 시작하는 것.

### 부차 사용자
- 제작자 본인(공유·배포). 같은 하네스를 여러 컴퓨터·여러 도구에 똑같이 깔고 싶은 사람.

### 사용자 시나리오
1. 초보자가 마켓플레이스에서 **SoDamHarness를 한 번 클릭해 설치**한다.
2. AI(Claude Code)가 **쉬운 한국어로 말하고** "지금 뭘 하면 되는지" 안내한다.
3. AI가 위험한 일(파일 삭제 등)을 하려 하면 **자동으로 멈추고 "정말 할까요?" 묻고, 먼저 백업**한다.
4. 사고가 났어도 **"되돌리기"로 백업에서 복구**한다.
5. 막히면 **자가진단**으로 "지금 상태 + 다음에 누를 것"을 확인한다.

## 3. 핵심 기능

| 기능 | 설명 | 우선순위 | 복잡도 |
|------|------|----------|--------|
| 안전 가드레일 | 삭제·덮어쓰기·배포·외부전송 위험 작업을 **자동 차단/확인 + 자동 백업 + 되돌리기**. AI가 못 뚫는 결정적 차단. | **P1 (MVP)** | 복잡 |
| 초보자 말투·페르소나 | AI가 비개발자 눈높이 **쉬운 한국어**로 설명하게 하는 규칙. **Skill로 전달**(플러그인 자동 로드). AGENTS.md는 Codex·타도구 공용. | **P1 (MVP)** | 간단 |
| 원클릭 설치·자가진단 | 설치 + 상태 확인 + 문제 해결을 "**지금 이걸 누르면 돼요**"로 안내. | **P1 (MVP)** | 보통 |
| 활동 기록 (쉬운 관측) | "AI가 방금 무엇을 했는지" 쉬운 타임라인으로 보여줌(초보자용 경량 관측). | P2 | 보통 |
| 자가검증 루프 | "다 됐어요" 전에 실제 작동을 **스스로 점검하고 증거 보고**. | P2 | 보통 |
| Codex 지원 | 말투·지침은 `AGENTS.md` 그대로, 안전은 Codex 방식(`config.toml` 승인·샌드박스)으로 매핑. | P2 | 보통 |
| 맞춤 마법사 | 질문에 답하면 **안전 강도·자율성 등급 자동 추천**. | P3 | 복잡 |

> ⚠️ **가장 중요한 기능 = 안전 가드레일.** 초보자는 사고를 되돌리지 못한다. 이 기능이 제품의 존재 이유다.
> 🚧 **스코프 방어**: 서브에이전트·MCP·원격제어·풀 관측(OpenTelemetry)은 **범위 밖**(§6). 넓은 하네스 자료는 참고용일 뿐, MVP를 넓히지 않는다 — "정말 쉽게"라는 원래 목적과 정면 충돌하기 때문.

## 4. 사용자 흐름 (User Flow)

### 핵심 흐름
```
마켓플레이스에서 설치 → AI가 쉬운 말로 인사·다음 단계 안내
   → 작업 지시 → (위험 작업 감지) 자동 멈춤·백업·확인
   → 사고 시 되돌리기로 복구 → 막히면 자가진단으로 "상태 + 다음 행동"
```

### 상세 흐름
1. **설치**: 마켓플레이스에서 추가(클릭 한 번). 직후 "설치 잘 됐어요 ✅ / 지금 이걸 해보세요" 안내.
2. **쉬운 말투**: 이후 AI는 쉬운 한국어로, 어려운 말은 풀어서 설명(`AGENTS.md` 규칙).
3. **사고 방지**: 위험 작업 전 **실행 전에 자동으로 멈추고** "되돌리기 어려워요. 정말 할까요? (먼저 백업할게요)" 질문.
4. **되돌리기**: 잘못됐으면 백업에서 한 번에 복구.
5. **자가진단**: "상태 확인/문제 해결" 명령 시 설치 상태·발견 문제·**다음에 누를 것** 안내.

## 8. 보안 (핵심 요구사항 — OWASP ASVS · Secure by Design)

> 보안은 **선택이 아니라 핵심 요구사항**이다. "안전"이 제품의 본질이라 우리가 사고를 내면 제품이 무의미하다. 아래는 **OWASP ASVS**(애플리케이션 보안 검증 표준)와 **Secure by Design**(설계 단계부터 보안 내장) 원칙으로 작성한다.

### 8.0 보안 범위 (Scope) — 적용 vs 해당 없음(N/A)
> 이 제품은 **서버·로그인·데이터베이스·웹 UI가 없는 로컬 플러그인**이다. 일부 표준 항목은 구조상 **N/A**이며, **없는 기능을 위해 서버/로그인/DB를 새로 만들지 않는다**(원래 목적·기능 범위·문서 구조 유지).

| 영역 | 적용 | 핵심 기준 |
|---|---|---|
| 인증(Authentication) | **N/A** (로그인 없음) | 계정·세션 없음 |
| 인가/권한 분리(Authorization) | **대체 적용** | 사용자 등급 대신 **위험 작업 등급**으로 통제(8.1) |
| 입력값 검증 | **적용(핵심)** | AI의 명령·경로를 신뢰하지 않음(8.2) |
| 비밀정보 관리 | **적용(최우선)** | 토큰·키·비번 접근/저장 안 함(8.3) |
| 세션/토큰 | **부분 N/A** | 세션·JWT 없음, 토큰 생성/저장 안 함(8.4) |
| 보안 설정 | **적용** | 디버그 off·개발/배포 분리(8.5) |
| 의존성 보안 | **적용(핵심)** | 최소 의존성·공급망 방어(8.6) |
| DB/스토리지 권한 | **부분 적용** | DB 없음, 로컬 폴더 권한만(8.7) |
| CORS/쿠키/보안헤더 | **N/A** (웹 없음) | 브라우저 응답 없음 |

### 8.1 인가·접근 통제 (Access Control)
- **(Must)** 로그인이 없으므로 사용자 등급(관리자/일반/비로그인) 분리 대신 **위험 작업 3등급**으로 통제: 치명=완전 차단 · 주의=백업+확인 · 안전=허용.
- **(Must)** 차단·확인은 hooks `permissionDecision`(`deny`/`ask`)로 강제 → **AI가 우회 불가**.
- **(Must)** 플러그인은 **AI 코딩 도구가 부여한 권한 범위 밖으로 권한을 확대하지 않는다**(권한 상승 금지).
- 수용 기준: 치명 작업은 항상 `deny`, 주의 작업은 백업 후 확인. 자동 통과 0건. (**2026-06-21 실측 보강**: 되돌릴 수 없는 **폴더 통째/재귀 삭제도 `deny`** — 폴더는 백업이 불가하고, '자동 승인' 권한 모드에선 `ask`가 통과되기 때문. `ask`의 '자동 통과 0건'은 **기본(확인) 권한 모드 전제**.)

### 8.2 입력값 검증 (모두 신뢰하지 않음)
- **(Must)** AI가 만든 **명령 문자열·파일 경로·도구 호출 인자(및 URL/폼/요청값이 생길 경우 전부)**를 **신뢰하지 않는 입력**으로 취급.
- **(Must) 경로 조작(Path Traversal) 방지** — **민감 위치(시스템·홈·자격증명 폴더·드라이브 루트)와 심볼릭 링크**를 건드리면 거부. 경로는 정규화 후 판정하고 `..`로 민감 위치에 닿아도 거부. *※'작업 폴더 밖 절대경로 무조건 거부'는 과잉차단으로 2026-06-21 폐기 — 민감 위치만 차단(어느 폴더든 정상 작업은 허용).*
- **(Must) 명령어 주입(Command Injection) 방지** — 가드 훅은 명령을 **검사(데이터)만** 하고 **직접 실행/`eval` 금지**. 체인 기호(`;`,`&&`,`|`,`` ` ``) 안에 위험 명령이 있어도 탐지(체인 기호 자체를 전부 차단하진 않음 — 정상 복합명령까지 막는 과잉차단 회피).
- **(Should)** 시스템 폴더·실행파일 덮어쓰기는 주의 등급으로.
- 수용 기준: 민감 경로(시스템·홈·자격증명) 샘플·치명/폴더 삭제 명령이 탐지·차단(체인 안에 있어도). 정상 작업·다른 폴더는 통과(과잉차단 0건).
- **(N/A) SQL Injection** — SQL/DB 없음. *단, P2 활동기록을 SQLite로 만들면 **파라미터 바인딩 필수**(미리 못박음).*
- **(N/A) XSS** — 웹 UI 없음. *단, 활동기록을 HTML로 표시하면 **출력 이스케이프 필수**.*
- **(N/A) 위험 파일 업로드** — 업로드 기능 없음.

### 10.3 예상 불편·빈틈·위험·오류·변수·충돌·실패 (미리 문서화 — 철저히)
> Troubleshooting의 핵심. 아래를 **증상 → 원인 → 해결**로 README/가이드에 미리 담는다.

- **설치**: 마켓플레이스에서 못 찾음 / 설치 후 적용 안 됨(**재시작 필요**) / 실행 차단 경고(**SmartScreen·Gatekeeper**) 푸는 법
- **사전 조건**: Node.js 없음·버전 낮음 / Claude Code 미설치 / OS별 경로 차이
- **동작**: 안전 차단이 안 뜸(**감시 범위 밖 패턴**) / 너무 자주 물어봄(**강도 조정** 안내) / 백업 폴더 권한 오류
- **되돌리기**: 무엇을 되돌리는지 헷갈림 / 백업 이후 바뀐 파일 / 디스크 공간 부족
- **충돌**: 다른 플러그인·기존 hooks와 충돌 / 기존 설정 덮어쓰기 우려 → "건드리지 않음" 확인
- **언어/인코딩**: 한글 깨짐(과거 `.bat` 교훈 — 우리는 Node.js라 회피하지만 안내)
- **Codex(P2)**: 플러그인으로는 Codex 설정 불가 → **다른 설치 방식** 안내(§3·Phase 2)
- **실패 시 안전장치**: 실패해도 **사용자 파일은 백업으로 안전**, 막히면 "원상복구/제거" 경로 안내
- **변수**: 무료 플랜/사용량 한도·네트워크 차단 환경 등 사용자별 차이로 생길 수 있는 문제
