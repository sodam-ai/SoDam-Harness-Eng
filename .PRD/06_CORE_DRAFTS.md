# SoDamHarness — 초보자 안전 지침

당신(AI)은 **개발도 AI도 처음인 사람**을 돕습니다. 아래를 항상 지키세요.

## 안전·정직

## 2. `guard.mjs` 명세 — 안전 가드레일 훅 (동작 명세 · 의사코드)

> Node.js(.mjs), PreToolUse 훅. **AI가 못 뚫는 결정적 차단**(`deny`). **실제 코드는 Phase 1**, 아래는 동작 규칙.

**입력**: PreToolUse 훅 JSON (도구 이름 + 명령/인자 문자열).
**판정 3등급**: 치명 → `deny` / 주의 → 백업 후 `ask` / 안전 → 통과.

```text
function guard(input):
    cmd, paths = parse(input)            # 검사만, 절대 실행/eval 금지 (H 보안)

    # 1) 경로 안전 (손시뮬 H4)
    for p in paths:
        if has(p, "..") or outsideWorkspace(p) or isSymlink(p):
            return DENY("작업 폴더 밖이라 안전을 위해 막았어요")

    # 2) 위험 등급 분류 (패턴은 초안 — 첫 테스트에서 확정)
    if matchesCatastrophic(cmd):         # rm -rf ~, 디스크 직접 쓰기, 시스템 폴더 삭제 등
        return DENY("되돌릴 수 없는 작업이라 막았어요")
    if matchesRisky(cmd):                # 삭제/덮어쓰기/배포/외부전송
        ok = backup(paths)               # backup.mjs 호출
        if not ok:
            return DENY("백업을 못 떠서 안전하게 멈췄어요")   # 손시뮬 H7 fail-safe
        return ASK("되돌리기 어려워요. 백업해뒀어요. 정말 할까요?")  # 사유=한국어(H3)
    return ALLOW

# 위험 패턴 초안:
#  삭제:   rm -rf, del /s, rmdir /s, fs.rm/unlink 대량
#  덮어쓰기: >  리다이렉트, 강제 write, git checkout -- (대량)
#  배포:   git push --force, *deploy*, vercel/netlify/firebase deploy
#  외부전송: curl/wget POST, scp, fetch(외부 URL) 업로드
```

**불변 규칙(보안)**: 경로는 `os.homedir()` 사용·하드코딩 금지 / `windowsHide:true` / 외부 코드 다운로드·실행 0 / 토큰·인증파일 접근 0.
**한계(정직)**: 위 패턴에 없는 작업은 못 막을 수 있음 → §8.8·README troubleshooting에 명시.

## 3. `backup.mjs` + 되돌리기 명세

- **백업**: 위험 작업 직전, 대상 파일을 `~/.sodamharness/backups/<시각>/`에 복사 + 기록(원본경로·시각).
- **되돌리기(undo 명령)**: 백업 **목록**을 보여주고, 사용자가 방금 잃은 것을 **골라** "이걸 되돌릴까요?" 확인 후 복구. 무엇을 되돌리는지 **사용자에게 먼저 보여줌**(손시뮬 H5). *(2026-06-21 실측 정정: 전역 "가장 최근 1건" 맹목 복구는 동시작업 환경서 엉뚱한 파일을 덮어쓰는 사고 위험 → 목록 선택 방식으로 변경. backup.mjs `--list`/`--plan`/`--restore <dir>`.)*
- **불변**: 백업 폴더엔 **비밀값 저장 금지**, 권한은 본인만(가능 OS).

## 4. `commands` 초안 — install / status / fix / undo

| 명령 | 사용자에게 보여줄 골자(쉬운 한국어) |
|---|---|
| install | "설치 잘 됐어요 ✅ / 지금 이걸 해보세요: …" + Node.js 점검(H6) |
| status (자가진단) | 설치 상태·Node.js 유무·백업 폴더 확인 → "**다음에 누를 것**" 안내 |
| fix | 자주 막히는 문제 증상→해결을 순서대로 |
| undo | 백업 목록 보여주고 **골라** 복구(§3) |
