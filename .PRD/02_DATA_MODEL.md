## 엔티티 상세

### 설정 프로필 (Profile)
한 사람/한 컴퓨터의 SoDamHarness 설정 묶음. (계정 없이 로컬 파일로 저장)

| 필드 | 설명 | 예시 | 필수 |
|------|------|------|------|
| id | 고유 식별자 (자동) | prof-001 | O |
| nickname | 사람이 알아볼 별칭 | "엄마 노트북" | X |
| target_tool | 적용 도구 | claude_code | O |
| autonomy_level | 자율성 등급(AI가 알아서 하는 정도) | **L1 (보수·확인 위주, 기본값)** | O |
| language | 언어 | ko | O |
| tone_level | 말투 강도(쉬움 정도) | "아주 쉽게" | O |
| safety_strength | 기본 안전 강도 | **ask_and_backup (기본값)** | O |
| created_at | 만든 날짜 (자동) | 2026-06-20 | O |

> 기본값 근거: 완전 초보자는 "알아서 처리"보다 **"물어보고 백업"**이 안전하면서 학습도 됨(01_PRD §8).

### 안전 규칙 (SafetyRule)
"어떤 위험 행동을 어떻게 다룰지" 한 줄 규칙. 프로필 하나에 여러 개.

| 필드 | 설명 | 예시 | 필수 |
|------|------|------|------|
| id | 고유 식별자 (자동) | rule-009 | O |
| profile_id | 어느 프로필 소속 | prof-001 | O |
| action_type | 위험 행동 유형 | 삭제 / 덮어쓰기 / 배포 / 외부전송 | O |
| decision | 처리 방식 | **확인(기본)** / 차단(치명적) / 허용 | O |
| do_backup | 실행 전 백업할지 | 예 | O |
| pattern | 어떤 명령을 잡을지(내부용) | rm -rf, git push --force | X |

### 백업 기록 (Backup)
위험 작업 전 자동으로 떠 둔 백업. 안전 규칙 하나에 여러 개. **되돌리기의 근거.**

| 필드 | 설명 | 예시 | 필수 |
|------|------|------|------|
| id | 고유 식별자 (자동) | bak-1023 | O |
| rule_id | 어느 안전 규칙이 떴는지 | rule-009 | O |
| source_path | 원본 위치 | D:\work\app\index.html | O |
| backup_path | 백업 저장 위치 | 홈폴더\.sodamharness\backups\... | O |
| created_at | 백업 시각 (자동) | 2026-06-20 14:02 | O |
| restorable | 되돌리기 가능 여부 | 예 | O |

### 진단 기록 (Diagnostic)
"상태 확인/문제 해결"을 돌릴 때마다 남는 점검 결과. 다음에 누를 것을 알려줌.

| 필드 | 설명 | 예시 | 필수 |
|------|------|------|------|
| id | 고유 식별자 (자동) | diag-077 | O |
| profile_id | 어느 프로필 점검 | prof-001 | O |
| checked_at | 점검 시각 (자동) | 2026-06-20 14:10 | O |
| tool_status | 도구 상태 | 정상 / 문제 | O |
| problem | 발견된 문제 | "백업 폴더 없음" | X |
| next_action | 다음 권장 행동 | "설치 메뉴 [1]을 누르세요" | O |

### 활동 기록 (Activity) — Phase 2 (초보자용 경량 관측)
"AI가 방금 무엇을 했는지" 쉬운 타임라인. (풀 관측/OTel 아님 — 초보자용 최소)

| 필드 | 설명 | 예시 | 필수 |
|------|------|------|------|
| id | 고유 식별자 (자동) | act-2051 | O |
| profile_id | 어느 프로필 | prof-001 | O |
| happened_at | 시각 (자동) | 2026-06-20 14:03 | O |
| summary | 쉬운 한국어 한 줄 | "index.html 파일을 고쳤어요" | O |
| linked_backup_id | 관련 백업(되돌리기용) | bak-1023 | X |

### 관계
- 설정 프로필 1 → 안전 규칙 N
- 안전 규칙 1 → 백업 기록 N → **되돌리기(복구)**
- 설정 프로필 1 → 진단 기록 N
- 설정 프로필 1 → 활동 기록 N (활동 → 백업 연결로 "이 작업 되돌리기" 가능)

## 왜 이 구조인가

- **단순성**: 초보자가 손댈 건 "설정 프로필" 하나. 나머지는 대부분 자동.
- **안전성**: 백업을 안전 규칙과 분리 → "무엇 때문에·언제·어디에" 백업했는지 추적·되돌리기 쉬움.
- **확장성**: 활동 기록(Phase 2)·자가검증 기록은 엔티티만 추가하면 됨. Codex는 `target_tool`에 `codex` 추가로 뼈대 유지.
- **보안**: 모든 정보는 내 컴퓨터 안. **토큰·비밀 저장 금지**(01_PRD §8). 계정·서버 불필요로 노출면 최소.
