SoDamHarness GUIDE

SoDamHarness 사용 설명서 (GUIDE) — 완전 초보자용

SoDamHarness(소담하네스) 는 AI(Claude Code)로 코딩할 때 실수로 큰 사고가 나지 않게 막아 주는 “안전벨트” 입니다. 개발도, AI도, 컴퓨터도 처음인 분이 그대로 따라 하기만 해도 되도록 만들었습니다.

⚠️ 가장 먼저 알아 둘 것 (정직한 약속): 이 도구는 흔한 위험을 막아 주는 “안전벨트” 이지, 모든 사고를 막는 “방탄막”이 아닙니다. “100% 안전”은 세상에 없습니다. 그래도 안전벨트는 사고 피해를 크게 줄여 줍니다.

0. 이게 뭔가요? (1분 이해)

AI와 내 컴퓨터 파일의 관계

AI에게 “이거 해 줘”라고 시키면, AI는 내 컴퓨터의 파일을 직접 만들고·고치고·지웁니다. 마치 내가 직접 파일을 다루는 것과 같습니다. 편리하지만, 문제가 하나 있습니다.

AI도 실수를 합니다. 예를 들어: - “이 파일 정리해 줘” 했는데 잘못된 파일을 지워 버리는 경우 - “폴더 좀 정리해 줘” 했는데 중요한 폴더 전체를 삭제하는 경우 - “코드 수정해 줘” 했는데 기존 내용이 통째로 바뀌는 경우

이런 일이 벌어지면 되돌리기가 매우 어렵습니다.

SoDamHarness가 하는 일

SoDamHarness는 AI와 내 파일 사이에 서서 문지기 역할을 합니다.

  • 🛑 아주 위험한 일(폴더 통째 삭제, 시스템 폴더 삭제 등)은 아예 막습니다.
  • 💾 되돌리기 어려운 일(파일 삭제·덮어쓰기) 전에는 자동으로 파일을 백업하고 “정말 할까요?” 라고 물어봅니다.
  • ↩︎️ 실수했어도 백업에서 되살릴 수 있습니다.
  • 🔒 비밀번호·토큰·인증 파일은 절대 건드리지 않고, 백업에도 저장하지 않습니다.
  • 🗣️ 모든 안내를 쉬운 한국어로 해 줍니다.

자동차 안전벨트처럼: 안전벨트가 있다고 운전을 거칠게 해도 된다는 뜻은 아닙니다. 하지만 사고가 났을 때 피해를 훨씬 줄여 줍니다.

0-1. 어떻게 작동하나요? (내부 구조·아키텍처)

💡 이 섹션은 “어떻게 동작하는지 원리가 궁금한 분”을 위한 것입니다. 당장 설치만 하고 싶으면 1번으로 건너뛰어도 됩니다.

동작 흐름

[사용자] → "파일 지워 줘" → [Claude Code(AI)]
                                     │
                                     ▼
                        [SoDamHarness 안전벨트 감시]
                                     │
          ┌──────────────────────────┼──────────────────────────┐
          ▼                          ▼                           ▼
     안전한 일                  위험한 일                 아주 위험한 일
  (파일 만들기 등)           (파일 삭제 등)            (폴더 통째 삭제 등)
          │                          │                           │
          ▼                          ▼                           ▼
     그냥 실행           백업 저장 + 확인 요청              즉시 차단
                        OK하면 실행 / 아니면 취소          (실행 안 함)

3등급 분류표

AI가 하려는 일을 안전벨트가 자동으로 3가지로 나눕니다.

등급 이름 어떤 일 안전벨트 반응
1등급 safe (안전) 파일 만들기, 파일 읽기, 일반 코드 편집, 새 폴더 만들기 그냥 실행 ✅
2등급 risky (위험) 파일 삭제, 파일 덮어쓰기, 배포 명령, 외부 전송 백업 💾 → 확인 요청 ⚠️ → 실행 or 취소
3등급 catastrophic (재앙) 폴더 통째 삭제(rm -rf), 시스템 폴더 삭제, Windows/Program Files 삭제 즉시 차단 🛑 (실행 불가)

어떤 파일들이 이 일을 하나요?

파일 이름 별명 하는 일
hooks/guard.mjs 경비원 AI가 도구를 쓰기 전에 실행돼서 위험도를 판단하고 막거나 허용
hooks/backup.mjs 백업 담당 위험한 작업 전 파일을 ~/.sodamharness/backups/에 자동 저장
hooks/whitelist.mjs 허가 목록 /sodam-harness-trust로 “이건 안 물어봐도 돼”라고 등록한 목록 관리
hooks/activity.mjs 일지 기록원 AI가 한 일을 ~/.sodamharness/activity.log에 기록 (파일명·시각만, 비밀 마스킹)
hooks/safety-rules.json 규칙집 위험 패턴 목록 (guard.mjs가 이 파일을 읽어서 판단)
commands/ 명령 모음 사용자가 /sodam-harness-...를 치면 실행되는 6개 명령

비유로 이해하기: guard.mjs는 건물 앞 경비원, backup.mjs는 금고 담당 직원, whitelist.mjs는 VIP 명단, activity.mjs는 방문자 출입 기록부입니다. safety-rules.json은 경비원이 들고 다니는 “위험 목록 수첩”입니다.

1. 사전 준비물 (필요한 프로그램)

딱 2가지만 있으면 됩니다.

(1) Node.js — 안전벨트 엔진

Node.js가 뭔가요? 웹사이트·앱·프로그램을 만들 때 쓰는 무료 도구입니다. SoDamHarness의 안전 기능은 Node.js로 만들어져 있어서 반드시 필요합니다. (비용: 완전 무료)

이미 있는지 확인하는 방법 (윈도우):

  1. 키보드에서 ⊞ 윈도우키 를 누릅니다.

  2. powershell 이라고 입력합니다.

  3. Windows PowerShell 이라는 항목을 클릭합니다.

  4. 검은 창이 열리면, 아래를 입력하고 Enter:

    node --version

  5. v18.19.0 처럼 v18 이상 숫자가 나오면 이미 설치됨 (예: v22.19.0). 'node'은(는) 내부 또는 외부 명령... 이라고 나오면 없는 것.

없으면 설치하는 방법 (윈도우):

  1. 웹브라우저(크롬·엣지 등)를 엽니다.
  2. 주소창에 https://nodejs.org 를 입력하고 Enter.
  3. 초록색 “LTS” 버튼을 클릭합니다. (LTS = Long Term Support = 안정 버전. “Current” 말고 반드시 “LTS” 를 선택하세요.)
  4. 내려받기가 끝나면 내려받은 파일(node-v**.msi)을 더블클릭합니다.
  5. 설치 창이 열리면 “다음(Next)” 버튼만 계속 누릅니다. (설정은 바꾸지 않아도 됩니다.)
  6. “설치(Install)” → 설치 완료 → “마침(Finish)”.
  7. 컴퓨터를 껐다 켭니다 (또는 PowerShell 창을 닫고 새로 엽니다).
  8. 위 확인 방법으로 v18 이상이 나오면 성공.

이미 있는지 확인하는 방법 (맥):

  1. 키보드 Cmd + Space → 터미널 입력 → 터미널 클릭.

  2. 아래를 입력하고 Return:

    node --version

  3. v18 이상이면 이미 설치됨.

없으면 설치 (맥): https://nodejs.org 에서 LTS 버튼 클릭 → .pkg 파일을 더블클릭해서 설치.

⚠️ 맥 주의: SoDamHarness는 현재 윈도우에서만 실제 검증했습니다. 맥에서도 동작하도록 만들었지만 미검증입니다.

(2) Claude Code — AI 코딩 도구 (이 안전벨트가 붙는 곳)

Claude Code가 뭔가요? Anthropic(앤트로픽)이라는 회사가 만든 AI 코딩 도우미입니다. 터미널(검은 명령창)에서 실행하며, “이 코드 고쳐 줘”, “파일 만들어 줘” 같은 자연어 지시를 이해하고 실제로 실행합니다. SoDamHarness는 Claude Code 위에 설치되는 안전벨트 플러그인입니다.

이미 이 글을 Claude Code에서 보고 있다면 설치되어 있는 것입니다.

비용 안내: - Node.js: 완전 무료 - Claude Code: Anthropic에서 제공. 무료 플랜과 유료 플랜이 있습니다. 정확한 요금은 공식 사이트 https://claude.ai 에서 확인하세요. (본 도구는 Anthropic과 공식 제휴 관계가 없으며, 요금 정보는 변경될 수 있습니다.)

💡 “검은 명령창(터미널)”이 뭔가요? 컴퓨터에 글자로 명령을 내리는 창입니다. 여는 법(윈도우): 키보드 ⊞ 윈도우키 → powershell 입력 → Windows PowerShell 클릭. 여는 법(맥): Cmd + Space → 터미널 입력 → 클릭.

1-1. 다운로드 방법

SoDamHarness 파일을 내 컴퓨터에 가져오는 방법 3가지입니다. 지금 상황에 맞는 방법 하나를 선택하세요.

방법 A — GitHub에서 ZIP으로 내려받기 (공개 후 / 일반 사용자 추천)

⚠️ 현재 기준: 아직 GitHub에 공개되지 않아 이 방법은 사용할 수 없습니다. 공개된 후에 이 방법을 쓰세요.

GitHub는 프로그램 파일을 올려두는 인터넷 저장소입니다. ZIP 파일로 한 번에 내려받을 수 있습니다.

  1. 웹브라우저에서 https://github.com/sodam-ai/SoDam-Harness-Eng 접속.
  2. 화면 오른쪽 초록색 “Code” 버튼을 클릭합니다.
  3. 드롭다운 메뉴에서 “Download ZIP” 을 클릭합니다.
  4. ZIP 파일이 내 컴퓨터 “다운로드” 폴더에 저장됩니다.
  5. ZIP 파일을 우클릭 → “모두 압축 풀기(Extract All)” → 원하는 폴더에 압축 해제.
    • 경로에 한글이 없는 곳을 추천합니다. 예: C:\SoDam-Harness-Eng\
  6. 압축 해제된 폴더의 전체 경로를 메모해 둡니다. (설치할 때 필요)

방법 B — 개발자·지인에게 폴더째 받은 경우 (현재 방법)

✅ 지금은 이 방법을 쓰세요.

개발자나 지인에게 폴더째 받았거나, USB·공유 폴더로 받은 경우입니다.

  1. 받은 폴더를 내 컴퓨터에 복사합니다.
    • 예: D:\SoDam-Harness-Eng\ 또는 C:\Users\내이름\SoDam-Harness-Eng\
    • 경로에 한글이 없는 곳을 추천합니다.
  2. 폴더 안에 plugin.json, hooks/, commands/ 폴더가 있으면 정상입니다.
  3. 이 폴더의 전체 경로를 메모해 둡니다. (설치할 때 붙여넣어야 합니다.)

전체 경로 확인 방법 (윈도우): - 탐색기(파일 탐색기)에서 폴더를 엽니다. - 위쪽 주소창(경로 표시 부분)을 클릭하면 전체 경로가 텍스트로 나타납니다. - Ctrl+A (전체 선택) → Ctrl+C (복사)합니다.

방법 C — Git Clone (중급자·개발자용)

이미 Git을 사용하는 분이라면 터미널에서:

git clone https://github.com/sodam-ai/SoDam-Harness-Eng.git

1-2. Claude Code 설치 방법

💡 이미 Claude Code를 쓰고 있다면 이 섹션은 건너뛰어도 됩니다.

Claude Code가 뭔가요?

Claude Code는 Anthropic(앤트로픽)이 만든 AI 코딩 도우미입니다. 터미널(검은 명령창)에서 실행하며, “이 코드 고쳐 줘”, “파일 만들어 줘” 같은 자연어 지시를 이해하고 실제로 실행합니다. SoDamHarness는 Claude Code 위에 설치되는 플러그인이라 Claude Code 없이는 동작하지 않습니다.

구독·요금 안내

Claude Code는 Anthropic의 API 사용량에 따라 요금이 발생합니다. 정확한 요금 정책은 공식 사이트에서 확인하세요: - 공식 사이트: https://claude.ai - Claude Code 안내: https://claude.ai/claude-code

⚠️ 안내: 본 도구(SoDamHarness)는 Anthropic과 공식 제휴 관계가 없습니다. 요금·플랜 정보는 언제든 바뀔 수 있으니 반드시 공식 사이트에서 최신 정보를 확인하세요.

Claude Code 설치 단계

사전 조건: Node.js가 먼저 설치되어 있어야 합니다 (위 1번 참고).

  1. 터미널(검은 명령창)을 엽니다.

    • 윈도우: ⊞ 윈도우키 → powershell → Windows PowerShell 클릭.
    • 맥: Cmd + Space → 터미널 입력 → 터미널 클릭.

  2. 아래를 입력하고 Enter:

    npm install -g @anthropic-ai/claude-code
    • npm은 Node.js와 함께 설치되는 프로그램 설치 도구입니다.
    • -g는 “내 컴퓨터 전체에 설치” 옵션입니다.
    • 설치에 1~3분 걸릴 수 있습니다.

  3. 설치가 끝나면 아래를 입력하고 Enter:

    claude

  4. 처음 실행하면 로그인·약관 동의 안내가 나옵니다. 화면 지시에 따라 진행합니다.

  5. Claude Code 입력칸이 나타나면 설치 성공입니다.

2. 설치 방법 (단계별)

설치는 딱 한 번만 하면 됩니다.

시작 전 체크리스트: - [ ] Node.js v18 이상 설치됨 - [ ] Claude Code 설치됨 - [ ] SoDamHarness 폴더의 전체 경로를 알고 있음

두 가지 방법 중 하나를 선택하세요.

방법 A — /plugin 화면으로 설치 (초보자 추천 · 화면 보고 클릭)

  1. Claude Code를 엽니다. (터미널에서 claude 입력 후 Enter)

  2. 입력칸에 /plugin 을 입력하고 Enter 합니다.

    • 플러그인 관리 화면이 열립니다.

  3. “마켓플레이스 추가(Add marketplace)” 항목을 선택합니다.

  4. 설치 소스를 입력합니다:

    • GitHub 공개 후(권장): sodam-ai/SoDam-Harness-Eng
    • 내 컴퓨터 폴더로 설치(현재 방법): 폴더의 전체 경로를 그대로 붙여넣습니다. 예시: D:\AI_Dev_Work\2026y\26y_06m_22d_SoDam-Harness-Eng

  5. 목록에서 sodam-harness 를 찾아 설치(Install) 를 누릅니다.

  6. Claude Code를 완전히 끄고 다시 켭니다.

    • 방법: /exit 입력 → 터미널 창도 닫기 → 터미널 새로 열기 → claude 입력.
    • ⚠️ 이 단계가 가장 중요합니다. 재시작하지 않으면 플러그인이 인식되지 않습니다.

  7. 입력칸에 /sodam-harness 를 입력합니다. 명령 목록이 나타나면 설치 성공입니다.

  8. /sodam-harness-install 을 입력해서 시작 안내를 받습니다.

방법 B — 명령으로 설치 (검은 명령창)

3. 빠른 시작 (3분)

설치 직후 처음 써 보는 방법입니다.

  1. Claude Code를 새로 엽니다. (재시작 완료 상태)

    • 예: test.txt 파일 만들어 줘 → 안전벨트가 막지 않고 그냥 만들어집니다. ✅
    • 예: 이 연습 폴더 통째로 지워 줘 → 🛑 안전벨트가 차단합니다. (안전!)

4. 사용·작동 방법 (안전벨트가 언제 어떻게 작동하나)

평소엔 평소처럼 AI에게 일을 시키면 됩니다. 위험한 순간에만 안전벨트가 나섭니다.

안전 동작 상세 표

AI가 하려는 일 구체적인 예 안전벨트 반응
파일 만들기 “readme.txt 만들어 줘” 그냥 진행 ✅
파일 읽기 “이 파일 내용 보여 줘” 그냥 진행 ✅
일반 편집 “이 코드 고쳐 줘” 그냥 진행 ✅
새 폴더 만들기 “src 폴더 만들어 줘” 그냥 진행 ✅
파일 삭제 “이 파일 지워 줘” 💾 백업 → ⚠️ 확인 요청
파일 덮어쓰기 “파일 내용 통째로 바꿔 줘” 💾 백업 → ⚠️ 확인 요청
배포 명령 “서버에 올려 줘” ⚠️ 확인 요청
파일 외부 업로드 curl/wget/scp로 파일 전송 (비밀키 유출 방지) ⚠️ 확인 요청
대량 삭제·초기화 find … -delete, truncate -s 0(파일 0-초기화) ⚠️ 확인 요청 (홈·폴더 대상이면 🛑)
폴더 통째 삭제 “이 프로젝트 폴더 지워 줘” 🛑 차단 (실행 불가)
시스템 폴더 삭제 Windows, Program Files 삭제 🛑 차단 (실행 불가)
rm -rf 등 강제 재귀 삭제 명령 🛑 차단 (실행 불가)
비밀번호·토큰·인증 파일 .env, auth.json, *.pem 등 🔒 접근 안 함·백업 제외

백업은 어디에?

위험한 작업 전 파일은 자동으로 ~/.sodamharness/backups/ 폴더에 저장됩니다. - 윈도우 예: C:\Users\내이름\.sodamharness\backups\ - 이 폴더에 비밀번호·토큰은 절대 저장하지 않습니다. - 실수로 지웠다면 /sodam-harness-undo 로 되살립니다.

자동 승인 모드 주의사항

Claude Code의 “자동 승인(YOLO)” 모드를 켜면 “정말 할까요?” 확인 창이 생략될 수 있습니다. 그래도 백업은 됩니다. 하지만 확인 창 없이 작업이 진행되므로, 위험 작업이 많다면 자동 승인 모드를 쓰지 않는 것을 권장합니다.

5-1. 보안·데이터 흐름

💡 “내 파일이 외부로 나가지 않나?”, “어떤 데이터가 저장되나?” 궁금한 분을 위한 섹션입니다.

완전 로컬 동작 (인터넷 없음)

SoDamHarness의 안전 기능은 설치 이후 인터넷이 전혀 필요 없습니다. 모든 동작이 내 컴퓨터 안에서만 일어납니다.

  • 경비원(guard.mjs): 내 컴퓨터 안에서 규칙집(safety-rules.json)을 읽어 판단
  • 백업(backup.mjs): 내 컴퓨터의 .sodamharness/backups/ 폴더에만 저장
  • 활동 기록(activity.mjs): 내 컴퓨터의 .sodamharness/activity.log에만 기록
  • 어떤 데이터도 외부 서버로 전송하지 않음

저장되는 것 vs 저장되지 않는 것

항목 저장 여부 저장 위치
작업한 파일의 내용 백업 (위험 작업 전) ✅ 저장됨 ~/.sodamharness/backups/ (내 컴퓨터만)
작업 파일 이름·시각 (활동 로그) ✅ 저장됨 ~/.sodamharness/activity.log (내 컴퓨터만)
파일 내용 (활동 로그에) ❌ 저장 안 됨 —
비밀번호·토큰·인증서 ❌ 절대 저장 안 됨 —
사용자 이름·이메일 등 개인정보 ❌ 수집 안 함 —
외부 서버 전송 ❌ 없음 —

절대 건드리지 않는 파일 목록

아래 파일들은 안전벨트가 절대 읽거나 백업하거나 수정하지 않습니다:

  • .env, .env.* (환경 변수 파일)
  • auth.json, credentials.json, token.json (인증 파일)
  • *.pem, *.key, *.crt (인증서·키 파일)
  • 윈도우: %AppData%\Microsoft\Credentials\ (시스템 자격증명)
  • 기타 민감 경로로 판단되는 파일

왜 이렇게 하나요? 실수로 백업 파일에 비밀번호가 포함되는 사고를 원천 차단하기 위해서입니다.

개인정보 관련

SoDamHarness는 개인정보를 수집하지 않습니다. 이름, 이메일, 사용 통계, 오류 보고 등 어떤 데이터도 외부로 나가지 않습니다.

백업 폴더 접근 권한 (Windows)

  • 백업 폴더(~/.sodamharness/backups/)는 따로 잠그지 않고, Windows가 기본으로 정하는 내 계정 폴더 권한에 그대로 의존합니다. 보통 이 컴퓨터의 다른 사용자 계정은 내 사용자 폴더 안을 볼 수 없습니다(윈도우 기본 동작).
  • 여러 사람이 같은 계정을 함께 쓰는 컴퓨터라면, 백업 폴더도 그 계정을 쓰는 사람 모두가 볼 수 있다는 점을 알아 두세요.

비공식 “AI 안전” 도구 주의

  • “AI 안전”을 내세우면서 로그인 토큰·비밀번호를 요구하는 비공식 도구는 특히 조심하세요. 실제로 그런 방식으로 로그인 정보를 몰래 빼간 사고가 있었습니다.
  • SoDamHarness는 어떤 토큰·비밀번호도 요구하지도, 저장하지도 않습니다. 어떤 도구든 로그인 정보를 달라고 하면 일단 의심하세요.

5-2. (선택) Codex(코덱스)에서도 쓰기

⚠️ 정직한 한계 먼저: SoDamHarness의 자동 차단·백업·되돌리기(undo)는 Claude Code 전용이라 Codex에선 동작하지 않습니다. Codex에선 Codex 자체 기능(승인 창 + 샌드박스) 으로 대신하며, 보호 방식·강도가 다릅니다. (“100% 안전”은 없습니다.)

Codex를 함께 쓰는 분을 위한 보조 설정입니다.

  1. 쉬운 말투 — 플러그인 폴더의 AGENTS.md 를 Codex로 작업할 프로젝트 폴더에 복사합니다. (기존 AGENTS.md가 있으면 덮어쓰지 말고 내용을 추가·병합.)

  2. 보수적 안전 설정 — 템플릿 codex/config.toml.example 의 두 줄(approval_policy, sandbox_mode)을 ~/.codex/config.toml 에 추가·병합합니다.

    • ⚠️ 기존 설정 덮어쓰기 금지.
    • ⚠️ ~/.codex/auth.json(로그인 토큰)은 절대 건드리지 않기.
    • ⚠️ 적용은 본인이 직접.
    • 값 이름은 Codex 버전마다 다를 수 있음 → 공식 문서: https://developers.openai.com/codex/config-reference

  3. 확인 — Codex를 다시 켜고 버려도 되는 빈 폴더에서 위험 작업을 시켜 승인 창이 뜨는지 확인합니다.

  4. 자세한 단계는 플러그인 폴더의 codex/CODEX_SETUP.md 에도 있습니다. 막히면 (Claude Code에서) “코덱스 안전 설정 도와줘” 라고 하세요.

6. 명령어 (언제 무엇을 쓰나)

입력칸에 /sodam-harness 까지 치면 아래가 자동완성으로 뜹니다. 모두 Claude Code 전용입니다.

/sodam-harness-install — 설치 확인 + 시작 안내

언제 쓰나: 처음 설치한 직후, 또는 “잘 설치됐나?” 확인할 때.

무슨 일이 일어나나: - 안전벨트가 제대로 켜져 있는지 확인 - 처음 쓰는 분을 위한 시작 안내

예시 출력:

✅ SoDamHarness 안전벨트가 켜져 있습니다.
💡 빠른 시작: 버려도 되는 폴더에서 AI에게 파일 삭제를 시켜 보세요.

/sodam-harness-status — 현재 상태 + 자가진단

언제 쓰나: “안전벨트가 지금 잘 작동하나?” 확인하고 싶을 때.

무슨 일이 일어나나: - 훅(경비원)이 켜져 있는지 점검 - 백업 폴더 상태 확인 - “다음에 할 일” 안내

/sodam-harness-fix — 문제 해결 안내

언제 쓰나: 뭔가 이상할 때, 명령이 안 먹힐 때, 안전벨트가 안 작동하는 것 같을 때.

무슨 일이 일어나나: - 증상을 물어봄 → 원인과 해결 방법 안내 - 재설치·재시작 안내도 포함

/sodam-harness-undo — 실수 되돌리기

언제 쓰나: AI가 파일을 잘못 지웠거나, 내용이 잘못 바뀌었을 때.

무슨 일이 일어나나: - 최근 백업 목록이 나타남 - 번호를 골라서 되살리기

예시 출력:

📁 최근 백업 목록:
1. readme.txt — 2026-06-28 14:32:11
2. config.json — 2026-06-28 13:15:44
3. index.js — 2026-06-27 18:02:30

몇 번 파일을 되살릴까요? (번호 입력):

⚠️ 주의: 폴더 통째는 차단(🛑)되므로 백업이 없습니다. 파일 단위 백업만 복구 가능합니다.

💾 백업 보관 기간: 백업은 최근 100개 + 30일까지 보관되고, 그보다 오래된 것은 새 백업이 뜰 때 자동 정리됩니다. 되돌리기는 이 범위 안에서 가능해요. (조정: ~/.sodamharness/safety-rules.json의 backupPolicy)

/sodam-harness-trust — 12시간 동안 안 묻기

언제 쓰나: 같은 작업에 매번 “정말 할까요?”가 떠서 귀찮을 때.

무슨 일이 일어나나: - “이 폴더에서 이 작업은 안 물어봐도 돼”를 등록 (폴더 + 작업종류 기준) - 차단(🛑)과 백업(💾)은 계속 유지됩니다. 확인 질문만 생략. - 12시간 후 자동 소멸. 세션(대화)을 새로 시작해도 유지됩니다 — 같은 폴더에서 같은 작업을 반복한다면 다시 물어보지 않아요.

⚠️ 주의: trust는 확인 질문을 줄이는 것이지, 차단과 백업을 없애는 게 아닙니다.

/sodam-harness-log — AI가 한 일 타임라인

언제 쓰나: “방금 AI가 뭘 했지?” 확인하고 싶을 때.

무슨 일이 일어나나: - AI가 한 작업 목록을 시간 순서로 보여줌 - 파일 이름과 시각만 표시 (파일 내용은 표시 안 함) - 비밀 파일(.env 등)은 이름도 마스킹(가림)

예시 출력:

📜 활동 기록 (최근 10건):
[2026-06-28 14:35] Write → readme.txt
[2026-06-28 14:33] Bash → (차단됨: 위험 명령)
[2026-06-28 14:32] Delete → old_file.txt (백업 완료)
[2026-06-28 14:30] Read → index.js

스킬 2개 (자동으로 도와주는 기능)

스킬은 명령처럼 직접 입력하는 것이 아니라, AI의 동작 방식을 자동으로 바꿔 줍니다.

이름 하는 일 어떻게 쓰나
sodam-harness-beginner-tone AI의 모든 안내를 쉬운 한국어 말투로 바꿔 줌 보통 자동 적용. 어렵게 느껴지면 “쉽게 설명해 줘”라고 한마디
sodam-harness-self-check AI가 “다 됐어요” 하기 전에 진짜 됐는지 스스로 점검하고 증거를 보여줌 자동 적용

💡 위 명령과 스킬은 모두 Claude Code 전용입니다. Codex에서 쓰는 법은 위 5-2번 섹션을 보세요.

7. 파일·문서 위치

내 컴퓨터에 자동 생성되는 폴더

설치 후 자동으로 아래 위치에 폴더가 생깁니다:

윈도우:

증상 왜 그런가 지금 할 것
/sodam-harness-... 명령이 안 떠요 설치 후 재시작을 안 함, 또는 설치가 안 됨 Claude Code를 완전히 껐다 켜기 → /sodam-harness 확인. 그래도면 2번(설치) 다시

“Node.js 없음” 이라고 떠요 안전 훅이 Node.js로 동작 https://nodejs.org 에서 LTS 설치 후 재시작 (위 1번 참고)
실행 차단 경고 (SmartScreen/Gatekeeper) 처음 보는 프로그램이라 OS가 한 번 물어봄 정상적으로 받은 파일이면 “실행 허용” 선택
실수로 파일을 지웠어요 — /sodam-harness-undo (목록에서 고르기)
폴더를 지웠어요 폴더 삭제는 차단(🛑)되므로 이 경우는 거의 없음 혹시라도 지워졌다면 /sodam-harness-undo 확인 (폴더 자체 복구는 불가)
백업 폴더 오류 (권한·용량) 디스크 가득참 또는 권한 문제 공간 확보 후 재시도. 백업 못 하면 위험 작업은 자동 중단됩니다
한글이 깨져요 터미널 인코딩 문제 보통 안 깨짐(Node.js). 그래도 깨지면 /sodam-harness-fix 입력

옛 이름(/install 등)·중복 명령이 떠요 이전 설치 잔재 Claude Code 완전 재시작. 그래도면 재설치

백업이 너무 많이 쌓여요 자주 작업하면 백업이 쌓임 .sodamharness/backups/ 폴더에서 오래된 것을 수동으로 삭제해도 됩니다

9. 제거(삭제) 방법

플러그인 제거

방법 A — 화면으로: 1. Claude Code에서 /plugin 입력. 2. 플러그인 목록에서 SoDamHarness 를 찾아 제거(Uninstall) 클릭. 3. Claude Code를 껐다 켭니다.

방법 B — 명령으로:

claude plugin uninstall sodam-harness@sodamharness-marketplace

백업 데이터 삭제 (선택)

플러그인을 지워도 백업 폴더는 자동으로 남습니다. 백업까지 지우려면:

  • 윈도우: 탐색기에서 C:\Users\내이름\.sodamharness\ 폴더를 찾아 삭제.
  • 맥: Finder에서 /Users/내이름/.sodamharness/ 삭제. (숨긴 폴더이므로 Cmd + Shift + . 으로 숨긴 파일 표시 후 삭제)

💡 백업을 남겨두고 싶으면 플러그인만 제거하고 .sodamharness/ 폴더는 그대로 두어도 됩니다.

10. 자주 묻는 질문 (FAQ)

Q1. 정말 안전한가요? “100% 안전”이라고 써 주세요.

A. 솔직하게 말씀드립니다. 흔한 위험은 막아 주지만 모든 경우를 100% 막진 못합니다. “안전벨트”이지 “방탄막”이 아닙니다. 예상치 못한 새로운 위험 패턴은 놓칠 수 있습니다. 진짜 중요한 자료는 이 도구만 믿지 말고 별도로 백업하세요. “100% 안전”을 보장하는 소프트웨어는 세상에 없습니다.

Q2. 제 비밀번호나 토큰을 몰래 보나요?

A. 아니요. SoDamHarness는 .env, auth.json, 인증서(*.pem, *.key) 등 민감한 파일에 접근하지 않습니다. 활동 로그에도 파일 내용은 기록하지 않고, 데이터를 외부로 보내지 않습니다. 백업에도 비밀 파일은 절대 포함하지 않습니다.

Q3. 인터넷이 필요한가요?

A. 설치할 때 한 번만 필요합니다. 그 이후 안전 기능 자체는 인터넷 없이 내 컴퓨터 안에서만 동작합니다.

Q4. 실수로 중요한 파일을 지웠어요. 어떻게 해요?

A. /sodam-harness-undo 를 입력하면 백업 목록이 나옵니다. 번호를 골라서 되살리세요. 단, 백업은 작업 직전에 자동으로 저장되므로, SoDamHarness가 설치되기 전이나 백업에 실패한 경우에는 되살리지 못할 수 있습니다. 중요한 자료는 별도 백업을 꼭 하세요.

Q5. 맥(Mac)에서도 되나요?

A. 같은 코드로 동작하도록 만들었지만, 현재 윈도우에서만 실제 검증했습니다. 맥은 미검증 상태입니다. 맥에서 써 보시고 결과를 알려 주시면 도움이 됩니다.

Q6. Codex(코덱스)에서도 같은 보호가 되나요?

A. 아니요. 차단·백업·되돌리기는 Claude Code 전용입니다. Codex에서는 Codex 자체 승인 창과 샌드박스로 대신합니다. 자세한 내용은 위 5-2번 섹션을 보세요.

Q7. 이거 바이러스 아닌가요? 믿어도 되나요?

A. SoDamHarness는 오픈소스(Apache 2.0)이며 코드를 공개합니다. GitHub에서 코드를 직접 확인할 수 있습니다. 인터넷에 아무 데이터도 보내지 않으며, 내 컴퓨터 안에서만 동작합니다. 걱정되신다면 IT 전문가에게 코드를 보여드리고 확인 받으시는 것을 권장합니다. “무조건 믿어도 된다”고 보장하지는 않습니다 — 오픈소스를 직접 확인하는 것이 가장 안전합니다.

Q8. 왜 Node.js가 필요한가요? 저는 코딩을 안 해요.

A. SoDamHarness의 안전 기능(경비원·백업·기록)이 Node.js라는 프로그램으로 만들어져 있기 때문입니다. Node.js는 이 도구를 동작시키는 엔진 역할입니다. 코딩을 전혀 몰라도 설치만 하면 되고, 한 번 설치하면 다시 신경 쓸 일이 없습니다. (완전 무료입니다.)

Q9. 배터리나 컴퓨터 속도에 영향을 주나요?

A. 거의 없습니다. SoDamHarness는 AI가 작업을 할 때만 잠깐 실행되고, 평소엔 대기 상태입니다. 파일 하나 백업하는 데 걸리는 시간은 1초 미만이며, CPU·메모리 사용량도 매우 적습니다.

Q10. 백업 파일이 너무 많이 쌓이면 어떻게 하나요?

A. 대부분 자동으로 정리됩니다. 백업은 최근 100개 + 30일까지 보관되고, 그보다 오래된 것은 새 백업이 생길 때 자동으로 정리됩니다(한 번에 최대 200개). 그래도 더 줄이고 싶으면 ~/.sodamharness/backups/ 폴더(윈도우: C:\Users\내이름\.sodamharness\backups\)에서 오래된 .bak 파일을 직접 삭제해도 됩니다. 보관 기준은 ~/.sodamharness/safety-rules.json의 backupPolicy(keepN·keepDays)로 조정할 수 있습니다.

Q11. 팀원·회사에서 같이 써도 되나요?

A. 네. Apache 2.0 라이선스이므로 상업적 사용, 회사 도입, 팀 사용 모두 허용됩니다. 다만 라이선스·저작권 고지를 유지해야 하고, 변경한 부분은 명시해야 합니다. 자세한 내용은 아래 11번 섹션을 보세요.

Q12. Claude Code 없이 써도 되나요?

A. 아니요. SoDamHarness는 Claude Code의 플러그인(훅) 입니다. Claude Code 없이는 동작하지 않습니다.

Q13. 안전벨트가 너무 자주 물어봐서 귀찮아요.

A. /sodam-harness-trust 명령으로 “이 폴더에서 이 작업은 안 물어봐도 돼”라고 등록하면 됩니다. 폴더+작업종류 기준으로 12시간 동안 유지되며, 대화(세션)를 새로 시작해도 초기화되지 않습니다. 또한 Claude Code의 자동 승인(YOLO) 모드를 켜면 확인 창이 생략됩니다 (백업은 유지됩니다).

Q14. /sodam-harness-trust 를 하면 차단도 해제되나요?

A. 아닙니다. trust는 “정말 할까요?”라는 확인 질문만 생략합니다. 차단(🛑)과 백업(💾)은 trust 이후에도 계속 유지됩니다.

Q15. 이 도구를 수정해서 배포하거나 팔아도 되나요?

A. 네, Apache 2.0 라이선스이므로 수정·재배포·판매가 허용됩니다. 다만 반드시: 라이선스 고지 보존, 저작권 고지 보존, 변경 사항 명시, NOTICE 파일 동봉(있는 경우)을 해야 합니다. 자세한 내용은 11번 섹션과 LICENSE 파일을 참고하세요.

Q16. “자동 승인(YOLO) 모드”가 뭔가요?

A. Claude Code의 설정 중 하나로, 모든 작업에 “예”를 자동으로 눌러 주는 모드입니다. 이 모드에서는 SoDamHarness의 “정말 할까요?” 확인 창이 생략될 수 있습니다. 그래도 백업은 됩니다. 위험한 작업이 걱정된다면 자동 승인 모드를 끄는 것을 권장합니다.

Q17. “114개 셀프테스트 통과”가 무슨 뜻인가요?

A. SoDamHarness 개발 과정에서 114가지 테스트 케이스(위험 차단·백업·되돌리기·경계 상황·적대적 우회 시도 등)를 직접 실행해서 모두 통과했다는 의미입니다. “기본 기능이 의도대로 동작한다”는 것을 확인한 것이지, “모든 상황에서 100% 완벽”하다는 의미는 아닙니다.
