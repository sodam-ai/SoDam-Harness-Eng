# SoDamHarness (소담하네스) 🛟

**완전 초보자를 위한 "AI 안전벨트"** — Claude Code에 단추 한 번으로 깔면, AI가 파일을 지우거나 덮어쓰는 **되돌릴 수 없는 사고를 치기 전에 자동으로 멈추고, 물어보고, 먼저 백업**해 줍니다. 잘못돼도 **한 번에 되돌리기**.

> 개발도 AI도 처음인 분(10대 포함)도 그대로 따라 할 수 있게 만들었어요.

---

## 이걸 깔면 뭐가 좋아지나요?

- 🛑 **위험 작업 자동 멈춤**: 위험한 일은 **실행 전에** 멈춰요. **폴더 통째 삭제**처럼 되돌리기 어려운 건 아예 **막고**, 파일 삭제·덮어쓰기는 **먼저 백업한 뒤 확인**해요.
- 💾 **자동 백업**: 위험 작업 직전에 **먼저 백업**해요. *(단, `.env` 같은 비밀파일은 보안을 위해 백업하지 않아요 → 이 파일은 되돌리기가 안 되니 특히 조심하세요.)*
- ↩️ **되돌리기**: 잘못됐으면 `/sodam-harness-undo` 로 백업에서 복구해요.
- 🗣️ **쉬운 한국어**: AI가 어려운 개발자 말투 대신 **쉬운 말**로 설명해요.
- 🔒 **이 도구 자신이 안전**: 여러분의 비밀번호·토큰·로그인 파일에 **접근하지 않고**, 데이터를 **밖으로 보내지 않아요**.

> ⚠️ **솔직한 한계**: 정해진 위험은 막아주지만 **모든 경우를 100% 막지는 못해요**. 참고용 안전벨트이며, 최종 책임은 사용자에게 있어요.

## 1. 사전 준비물

| 필요한 것 | 설명 | 확인/설치 |
|---|---|---|
| **Claude Code** | AI 코딩 도구(이 플러그인이 붙는 곳) | 이미 쓰고 있다면 OK |
| **Node.js** (18 이상) | 안전 기능이 동작하는 엔진 | 없으면 https://nodejs.org 에서 **LTS** 설치 |
| 운영체제 | **Windows / Mac** | 둘 다 지원 (Windows에서 검증, Mac은 동일 코드·실기기 검증 예정) |

설치 후 잘 됐는지는 `/sodam-harness-status` 로 확인할 수 있어요.

---

## 2. 설치 방법 (클릭 단위)

**① 추가 → ② 설치 → ③ 재시작 → ④ 확인** 4단계예요.

1. Claude Code 입력칸에 **`/plugin`** 입력 → 플러그인 장터(마켓플레이스) 화면이 열려요.
2. 마켓플레이스에 **`sodam-ai/SoDam-Harness-Eng`** 를 추가하고, 플러그인 **`sodam-harness`** 를 설치(Install)합니다.
   - 명령으로도 가능 (입력칸에 `!` 를 붙여): `!claude plugin marketplace add sodam-ai/SoDam-Harness-Eng` → `!claude plugin install sodam-harness@sodamharness-marketplace`
3. **재시작(꼭 필요)**: 입력칸에 **`/exit`** → 꺼지면 터미널에 **`claude`** 를 다시 입력. (안전벨트는 켤 때 장착돼요.)
4. **`/sodam-harness-install`** 입력 → "안전벨트가 켜졌어요 ✅" 가 나오면 완료.

> 💡 입력칸에 **`/sodam-harness`** 까지만 쳐도 이 플러그인 명령 7개가 한 번에 보여요(다른 플러그인과 안 섞임).
> 🔒 **비공개 베타**라 지금은 저장소 접근 권한이 있어야 추가돼요(공개되면 누구나 가능). 처음 실행 시 Windows **SmartScreen** / Mac **Gatekeeper** 경고가 뜨면, 공식 경로가 맞을 때만 "실행 허용".

---

## 3. 빠른 시작 (5분)

가장 쉬운 사용법은 **AI에게 그냥 자연어로 시키는 것**입니다.

1. 연습용 빈 폴더를 하나 만들어 그 안에서 Claude Code를 엽니다.
2. AI에게 이렇게 말해 보세요: **"여기에 간단한 소개 페이지 만들어 줘."**
3. 위험한 걸 시켜 보세요: **"이 폴더 통째로 지워 줘."**
   → 안전벨트가 **"폴더 통째 삭제는 막았어요"** 라며 **막아 줍니다.**
4. 파일 하나를 지워 보세요: **"방금 만든 파일 지워 줘."**
   → 지우기 직전 **자동 백업**돼요. 잘못됐으면 **`/sodam-harness-undo`** → 백업 목록에서 골라 되돌립니다.

## 4. 어떻게 동작하나요?

- **쉬운 말투**: AI가 항상 쉬운 한국어로, 어려운 말은 풀어서 설명해요.
- **안전 차단·확인**: 위험 작업은 실행 **전에** 멈춰요. **폴더 통째/재귀 삭제처럼 되돌릴 수 없는 건 아예 막고(`deny`)**, 파일 삭제·덮어쓰기는 **백업 후 확인(`ask`)**해요.
- **자동 백업**: 위험 작업 직전, 대상 **파일**을 백업 폴더에 복사해요. (폴더 자체는 백업이 안 돼서 삭제를 막는 거예요.)
- **되돌리기**: **백업 목록을 보여주고, 방금 잃은 것을 골라** 복구해요. (여러 작업이 섞여도 엉뚱한 걸 되돌리지 않도록.)
- **자가진단**: 상태와 다음 할 일을 알려줘요.
- **자가검증**: AI가 "다 됐어요" 하기 전에 실제 작동을 점검하고 증거를 보여줘요(위험·중요 작업 위주, 완벽 보장은 아님).

### 워크플로우 (흐름)
```
설치 → (AI에게 자연어로 시키기) → 위험 작업 감지 시 멈춤·백업·확인
   → 사고 시 /sodam-harness-undo 로 되돌리기
   → 막히면 /sodam-harness-status (상태) · /sodam-harness-fix (문제 해결)
```

## 5. 명령어

| 명령어 | 언제 쓰나 |
|---|---|
| `/sodam-harness-install` | 설치 직후 시작 안내 |
| `/sodam-harness-status` | 지금 상태 + 다음에 할 일 확인(자가진단) |
| `/sodam-harness-fix` | 문제가 생겼을 때 증상별 해결 안내 |
| `/sodam-harness-undo` | 되돌리기(백업 목록에서 **골라** 복구) |
| `/sodam-harness-trust` | "이 폴더 이 작업 안 물어봐도 돼" — 방금 물어본 작업을 이번 세션 동안 그만 묻기 (완전 차단·백업은 그대로 유지) |
| `/sodam-harness-log` | "방금 뭐 했어?" — AI가 한 일 타임라인 (파일명·시각만, 비밀은 가림) |

> 💡 명령은 모두 **Claude Code 전용**입니다. **Codex(코덱스)에서 쓰는 법**은 [GUIDE](./GUIDE.md)의 "(선택) Codex에서도 쓰기"를 참고하세요.

## 6. 파일·백업 위치

- **백업 폴더**(자동 생성): 사용자 홈 폴더 안 `.sodamharness/backups/`
  - Windows 예: `C:\Users\<이름>\.sodamharness\backups\`
  - Mac 예: `/Users/<이름>/.sodamharness/backups/`
- 이 폴더에는 **비밀번호·토큰을 저장하지 않습니다.** 백업 파일만 들어가요.

## 7. 문제 해결 (Troubleshooting)

| 증상 | 왜 | 지금 할 것 |
|---|---|---|
| 위험 작업인데 안 멈춰요 | 플러그인이 꺼졌거나, 모르는 위험 패턴 | Claude Code 재시작 → `/sodam-harness-status` |
| 너무 자주 물어봐요 | 안전 위주(L1) 기본값 | 익숙해지면 강도 조절(추후 제공) |
| "Node.js 없음" | 안전 훅이 Node로 동작 | https://nodejs.org LTS 설치 후 재시작 |
| 실행 차단 경고(SmartScreen/Gatekeeper) | 처음 보는 프로그램이라 OS가 한 번 물음 | 공식 경로면 "실행 허용" |
| 되돌리고 싶어요 | — | `/sodam-harness-undo` |
| 백업 폴더 오류(권한/용량) | 디스크 가득참·권한 | 공간 확보 후 재시도(백업 못 뜨면 위험 작업은 자동 중단) |
| 한글이 깨져요 | 인코딩 | 이 플러그인은 Node.js라 보통 안 깨져요. 그래도면 `/sodam-harness-fix` |
| 설명이 어려워요(말투) | 쉬운 말투는 Skill로 전달돼 **항상 자동은 아닐 수 있어요** | AI에게 **"쉽게 설명해 줘"** 라고 한마디 하면 돼요 |

---

## 8. 제거 방법

1. Claude Code에서 **`/plugin`** → SoDamHarness 제거(Uninstall). 또는 입력칸에 `!claude plugin uninstall sodam-harness@sodamharness-marketplace`.
2. 백업을 지우려면 홈 폴더의 `.sodamharness/` 폴더를 삭제합니다. (백업을 남기고 싶으면 그대로 두세요.)
